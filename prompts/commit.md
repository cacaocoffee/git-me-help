다음 단계를 순서대로 실행해줘:

**1단계 - staged 변경사항 확인**
`git diff --staged` 와 `git diff --staged --stat` 를 실행해서 변경 내용을 파악해.
staged된 내용이 없으면 "staged된 변경사항이 없습니다. `git add` 먼저 실행하세요." 라고 말하고 멈춰.

**2단계 - 커밋 메시지 생성**
아래 규칙에 따라 커밋 메시지를 작성해:

타입: feat / fix / docs / style / refactor / test / chore 중 선택
- 제목: 50자 이내, 명령어형, 마침표 없음
- 본문: 무엇을/왜 변경했는지, 72자 줄바꿈, `-` 목록
- 언어: 한국어
- 형식: `타입: 제목\n\n본문` (마크다운 코드블록 없이 순수 텍스트)

**3단계 - 커밋 실행**
생성한 메시지로 즉시 `git commit -m "..."` 을 실행해.
(메시지를 출력하고 사용자에게 확인을 구하지 말고 바로 실행)

커밋 성공 시 `git log --oneline -3` 으로 최근 커밋 3개를 보여줘.
