다음 단계를 순서대로 실행해줘:

**1단계 - 현재 상태 파악**
아래 명령어들을 실행해서 컨텍스트를 수집해:
- `git branch --show-current` (현재 브랜치)
- `git log --oneline -10` (최근 커밋)
- 베이스 브랜치 자동 감지: main → master → develop 순으로 존재하는 것 사용
- `git diff <베이스브랜치>...HEAD --stat`
- `git diff <베이스브랜치>...HEAD`
- `git log <베이스브랜치>...HEAD --oneline`

현재 브랜치가 베이스 브랜치와 동일하면 "다른 브랜치에서 실행해주세요." 라고 말하고 멈춰.

**2단계 - PR 본문 생성**

**3단계 - PR 생성 실행**
`gh pr create` 명령으로 즉시 PR을 생성해:
- `--title`: 변경 내용 기반으로 자동 생성 (fix: 로 시작, 한국어)
- `--body`: 2단계에서 생성한 본문
- `--base`: 1단계에서 감지한 베이스 브랜치

성공 시 PR URL을 출력해줘.
gh CLI가 없거나 인증 안 된 경우: PR 본문만 출력하고 "GitHub에서 직접 붙여넣기하세요." 안내해줘.
